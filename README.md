# 知华包装稿件审签

> 让被批准的稿件，就是最终发布的那一版。

由 [知华科技（上海如静知华信息科技有限公司）](https://www.zhuatech.cn/) 提供的 Java + H5 前后端分离企业软件社区源码版，数据库为 MySQL。

## 版本控制与发布

产品条码与文案 → 稿件任务 → 设计版本及附件 → 条码/文案核验 → 质量/法务/市场审签 → 发布清单 → 废止留痕

校验 EAN-13 校验位和必备文案，送审前必须上传实际文件。送审后版本及文件锁定，三个审核职能不能由同一人兼任；发布时保存附件摘要、文案版本及审核人清单，撤回后必须建立新版本。

| 模块 | 已实现功能 | 可执行操作 |
|---|---|---|
| 包装产品 | 产品条码与必备包装文案 | 新建、编辑、查询、详情、导出 |
| 稿件任务 | 关联版本、送审、独立审签和发布归档 | 指定版本送审、撤回修订、审批发布、废止版本 |
| 设计版本 | 可上传实际稿件附件，保存文案与条码快照 | 新建、编辑、查询、详情、导出 |
| 部门审签 | 质量、法务、市场必须由不同人员完成 | 同意稿件、拒绝稿件 |
| 发布清单 | 固定发布版本、附件摘要及审批人快照 | 业务动作自动生成、查询、追溯、导出 |

## 本机启动

```bash
docker compose --env-file .env.demo.example up --build -d
```

打开 http://localhost:8088 。演示账号：`admin / Demo-Admin-2026!`，`operator / Demo-Operator-2026!`，`reviewer / Demo-Review-2026!`，`viewer / Demo-Viewer-2026!`。另有 reviewer2、reviewer3，演示密码与 reviewer 相同，用于三个职能独立审签。这些均为公开的本机演示密码，禁止在公网或生产使用。

生产配置使用 `.env.example` 填入独立强密码，关闭 `DEMO_MODE`，详见 [部署与备份](docs/DEPLOYMENT.md)。演示模式只在空业务库中初始化数据，不会每次重启重置业务。

- 后端：Java 21 / Spring Boot 4.0.7 / JDBC / Flyway / MySQL 8.4，包名 `cn.zhuatech.artwork`。

### 明确的功能边界

一期管理稿件文件与文本合规检查，不做图像 OCR、自动识别包装图中的实际条码、印前分色或电子签章认证。审核人须人工查看实际附件；文字字段通过不等于图稿内容一定一致。

这是一套可运行、带业务测试的初版实现；测试通过不等于完成了所有生产环境的容量、安全、监管或现场验收。上线前需结合真实数据、业务制度和基础设施进行实施验证。
