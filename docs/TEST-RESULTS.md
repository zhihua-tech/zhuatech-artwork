## 验收内容

校验 EAN-13 校验位和必备文案，送审前必须上传实际文件。送审后版本及文件锁定，三个审核职能不能由同一人兼任；发布时保存附件摘要、文案版本及审核人清单，撤回后必须建立新版本。

所有接口测试通过实际 HTTP 调用进入 Spring 服务，关联数据通过再次读取或查询数量与金额进行验证。拒绝操作会核对没有新增成功业务流水与成功审计；并发测试覆盖同键重试和不同请求竞争同一版本。最新记录使用数据库顺序号，专门测试同一时间戳的排序。

## 范围限制

本次不包含第三方真实支付、邮件或硬件接入，不含生产容量压测、故障切换、渗透测试及行业合规认证。npm audit 仅反映检查时公开的前端依赖漏洞信息，不是全栈安全审计。

一期管理稿件文件与文本合规检查，不做图像 OCR、自动识别包装图中的实际条码、印前分色或电子签章认证。审核人须人工查看实际附件；文字字段通过不等于图稿内容一定一致。

## 复现

```bash
sh scripts/test.sh
```

默认使用 H2；在专用新建 MySQL 测试库设置 TEST_DB_URL / TEST_DB_USER / TEST_DB_PASSWORD 后执行 `mvn test` 可复现 MySQL 验收。禁止将测试运行指向生产库。
