# 主要功能验收矩阵

上海如静知华信息科技有限公司 · https://www.zhuatech.cn/

## 验收目标

产品条码与文案 → 稿件任务 → 设计版本及附件 → 条码/文案核验 → 质量/法务/市场审签 → 发布清单 → 废止留痕

| 模块 | 已实现功能 | 可执行操作 |
|---|---|---|
| 包装产品 | 产品条码与必备包装文案 | 新建、编辑、查询、详情、导出 |
| 稿件任务 | 关联版本、送审、独立审签和发布归档 | 指定版本送审、撤回修订、审批发布、废止版本 |
| 设计版本 | 可上传实际稿件附件，保存文案与条码快照 | 新建、编辑、查询、详情、导出 |
| 部门审签 | 质量、法务、市场必须由不同人员完成 | 同意稿件、拒绝稿件 |
| 发布清单 | 固定发布版本、附件摘要及审批人快照 | 业务动作自动生成、查询、追溯、导出 |

## 界面验收

检查业务端模块列表、新建与详情、服务端错误反馈，以及管理端账号权限和审计入口；桌面截图及管理端截图见 README。所有演示金额和人员均为虚构。

## 不宣称已覆盖的事项

一期管理稿件文件与文本合规检查，不做图像 OCR、自动识别包装图中的实际条码、印前分色或电子签章认证。审核人须人工查看实际附件；文字字段通过不等于图稿内容一定一致。

不将本机测试当成真实生产负载的压力测试，也不声称通过安全合规认证、故障切换或客户现场验收。测试事实见 [测试结果](TEST-RESULTS.md)。

## 增补安全与并发回归

四个不同请求同时修改同一版本，只允许一个成功；五次密码错误后暂时锁定；另一企业的 HTTP 会话无法读到单据、审计或附件；同一秒创建的记录使用数据库顺序号确定先后。
